# 21-数字时钟（DS1302 + 8位数码管 + LCD1602）

## 工程说明
- MCU：STC15F2K60S2 / IAP15F2K61S2 系列（与仓库原例程一致）
- RTC：复用 `20-DS1302时钟驱动` 的 DS1302 通信方式并扩展为 年/月/日/时/分/秒/星期 全读写
- 数码管：8位共阳极动态扫描，三屏轮显（每屏 6 秒）
  1. `hh-mm-ss`
  2. `yyyymmdd`（显示为 20xx 年）
  3. `001~007`（星期）
- LCD1602：用于模式、字段和值显示（校时/闹钟/参数）
- EEPROM：AT24C02 保存报时开关、闹钟总开关、2组闹钟参数

## 按键定义（矩阵键盘）
按用户给定风格（数字键 + 功能键），并将原 KEY_NONE 位置扩展为功能键：

- `0~9`：数字输入
- `KEY_COLON = 10`：设置页中“下一项/切换”
- `KEY_BACK = 11`：删除；在闹钟页切换“闹钟总开关”
- `KEY_ENTER = 12`：确认输入；在闹钟页切换当前闹钟启用
- `KEY_MODE = 13`（由 KEY_NONE 扩展）：进入校时 / 闹钟编辑
- `KEY_ALARM = 14`（由 KEY_NONE 扩展）：进入/退出闹钟参数页
- `KEY_CHIME = 15`（由 KEY_NONE 扩展）：整点报时开关

## 运行逻辑
- 常显模式：LCD 显示当前时间与状态，数码管按三屏循环
- 校时模式：按字段顺序 `Y M D h m s w` 输入与确认，最后写入 DS1302
- 闹钟模式：支持 2 组闹钟时刻（HH:MM），可逐组启停、总开关启停
- 整点报时：可开关；在整点触发蜂鸣
- 设置模式下数码管显示固定为时分秒（暂停三屏轮显）

## EEPROM 地址
- `0x00`：配置标记 `0x5A`
- `0x01`：整点报时开关
- `0x02`：闹钟总开关
- `0x03~0x05`：闹钟1（时、分、启用）
- `0x06~0x08`：闹钟2（时、分、启用）
